# Asset licences

Every asset of this repository is self-made and published under the repository licence (MIT).

| Files | Origin |
|---|---|
| `assets/*.png` (icon, adaptive icon layers, splash, favicon) | drawn in code by `scripts/make-icon.mjs` |
| `assets/sfx/*.wav` (ambience, steps, turns, click, chimes, exit chord, creak) | synthesised by `scripts/generate-sfx.mjs` |
| In-game textures (stone, planks, plaques, emblems, ghost, spider, cobweb) | painted in code at run time (`src/render/`) |

No font is bundled. The 7th Guest is named only as an inspiration: no asset comes from it and this project is not
affiliated with its authors.
